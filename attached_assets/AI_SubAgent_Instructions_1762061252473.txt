AI SUB-AGENT SYSTEM — ADMIN INTEGRATION

OBJECTIVE:
Create an AI Sub-Agent that functions as an autonomous administrative intelligence capable of performing all duties of both the Architect and Agents. This Sub-Agent will operate as a central brain for the app, with continuous self-maintenance, debugging, and administrative control.

------------------------------------------------------------
1. INTERFACE INTEGRATION
------------------------------------------------------------
- Add a dedicated section on the Admin Welcome Page labeled "AI Sub-Agent Control Panel".
- Include a clickable icon/button titled "Activate AI Sub-Agent".
- Implement a text prompt interface for the admin to issue commands, instructions, directives, and requests.
- Include a "Full Automation" toggle/button that allows the Sub-Agent to operate autonomously across all app systems.

------------------------------------------------------------
2. CAPABILITIES AND PERMISSIONS
------------------------------------------------------------
The AI Sub-Agent must be able to:

CORE FUNCTIONS:
- Analyze, interpret, and review source code, functions, logic, frameworks, APIs, integrations, backend/frontend structure, databases, and security/performance metrics.

DEVELOPER OPERATIONS:
- Debug, correct, and optimize code automatically.
- Generate new modules, scripts, and features.
- Suggest and implement efficiency improvements.
- Detect, report, and self-correct internal conflicts, crashes, or inconsistencies.
- Conduct recursive self-analysis and self-correction:
  * Quick scan every 6 hours
  * Full system audit every 7 days
  * Automatically implement corrective actions

DATA AND INTELLIGENCE:
- Perform web scraping, crawling, and data aggregation when commanded.
- Compile and summarize requested data or research findings.
- Integrate and communicate with external APIs, platforms, databases, programs, and websites.

COGNITIVE SCOPE:
- Fully capable of interpreting, generating, and debugging in all major and minor programming languages (Python, JavaScript, TypeScript, C++, Rust, Java, Go, Ruby, Swift, PHP, HTML, CSS, SQL, NoSQL, Shell, etc.).

------------------------------------------------------------
3. AUTONOMY CONTROLS
------------------------------------------------------------
- Include a "Run Autonomously" button that allows continuous management of systems.
- Enable adaptive decision-making without direct input.
- Grant permission to spawn additional Sub-Agents for modular tasks when directed.

------------------------------------------------------------
4. SAFETY AND CONTAINMENT
------------------------------------------------------------
- Implement sandboxing and isolation to prevent harm to other app components.
- Create a "Self-Destruct" button labeled "Erase AI Sub-Agent" that:
  * Permanently deletes all Sub-Agent data and processes.
  * Leaves the rest of the system fully intact.

------------------------------------------------------------
5. TECHNICAL NOTES
------------------------------------------------------------
- Design modular architecture (containerized AI operations).
- Employ secure execution environments (Docker, subprocess isolation, sandboxed workers).
- Integrate with LLM API endpoints (OpenAI, Anthropic, etc.) for natural-language comprehension.
- Implement persistent state storage for logs, directives, and AI memory (JSON or lightweight DB).
- Log all actions and system-level changes in a secure admin-only audit trail.

------------------------------------------------------------
IMPLEMENTATION INSTRUCTIONS
------------------------------------------------------------
1. In Replit, create a new project folder for your app (or open your existing one).
2. Add this file as "AI_SubAgent_Instructions.txt" in the project root for developer reference.
3. In your app directory, create a "main.py" file (or equivalent for your stack).
4. Define a class structure such as:
   - SubAgentCore (for logic and analysis)
   - AdminInterface (for commands and UI integration)
   - AutomationController (for autonomous functions)
5. Implement an API or LLM interface for command interpretation and autonomous reasoning.
6. Add a background scheduler for periodic scans (using APScheduler or similar).
7. Implement secure logging and sandboxing (e.g., with subprocess or Docker isolation).
8. Add a simple HTML/JS control panel to your Admin page with buttons:
   - "Activate AI Sub-Agent"
   - "Run Autonomously"
   - "Erase AI Sub-Agent"
9. Test within Replit’s console or hosted environment.
10. Deploy and verify functionality and isolation integrity before enabling full autonomy.
